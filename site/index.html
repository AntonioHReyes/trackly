MIT licensed · local-first

Time tracking that never leaves
your terminal

tck is a Toggl-style time-tracking CLI: workspaces per client, honest reports, PDF invoices — all backed by a single local SQLite file. No account, no browser tab, no subscription.

Install GitHub npm 
$ npm install -g @tonyakitori/trackly

$ tck workspace create acme "Acme Corp" --currency USD --rate 50
$ tck project create Website --client "Acme Corp" --rate 75
$ tck start "Fixing the checkout bug" --project Website
$ tck stop
$ tck report pdf --this-month -o report.pdf   # done

Why

Most time trackers are SaaS dashboards. tck is a single local SQLite database plus a CLI — built for freelancers and contractors juggling several clients who want start/stop timers, honest reports, and invoices that come straight out of the same data, without leaving the shell.

Features

Workspaces

One per client or context — projects, tags, and entries never mix across clients.

Timers & manual entries

start/stop a running timer, or add a completed entry with an explicit range.

Rates & earnings

Rates resolve project → workspace and freeze on the entry. tck earnings answers "how much did I make?" at a glance.

Clients

Tag a project with --client and slice reports, exports, invoices, and earnings by it across every project they own.

Reports & exports

PDF reports with charts, flat CSV exports, and ANSI bar charts straight in the terminal — sharing the same filters.

Invoices

PDF invoices priced from billable time, with tax, saved defaults, and an auto-incrementing number template.

MCP server

tck mcp exposes the same functionality as MCP tools, so Claude Desktop or Claude Code can manage your time tracking directly.

Backup & git-hook linking

A binary + diffable SQL backup on demand, and tck git-hook attach tags the running entry with the current commit.

Install

$ npm install -g @tonyakitori/trackly
$ tck --version

Requires Node.js ≥ 20. Full command reference and usage docs live in the README.
